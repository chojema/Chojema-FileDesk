[한국어](v0.4.0.md)

## New

- Right-click menus: the Explorer menu on Windows and a Finder-style menu on macOS (Open With, Get Info, Compress, Duplicate, Share and more)
- Drag and drop files and folders into, out of and between panes
- Date (weekday), time and keyboard input mode shown at the top right
- System file-type icons
- Option to hide the function key bar

## Changes

- FileDesk quits automatically after opening an update installer
- Information menu links moved to the About window

## Fixed

- Function key bar covering the panes in short windows
