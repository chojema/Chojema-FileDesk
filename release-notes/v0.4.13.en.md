## Changes

- Show cloud drives such as iCloud Drive, Dropbox, OneDrive and Google Drive in the drive bar automatically (each can be turned on or off in Settings)
- Fix an error when deleting items in cloud drives such as Synology Drive on macOS
- Use the default port when the server port is left blank, and keep an entered port when switching protocols
- Suggest choosing SFTP when connecting to an SFTP server with FTP/FTPS
