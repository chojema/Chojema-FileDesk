# Chojema FileDesk v0.2.0

출시일: 2026-11-07

[English](v0.2.0.en.md)

## 새 기능

- FTP, 명시적·암시적 FTPS, SFTP 서버 연결. 저장한 서버, 암호/SSH 개인 키 인증, 원격 시작 폴더와 연결할 패널 선택
- 두 패널에서 파일·폴더 업로드/다운로드, 복사·이동·이름 변경·새 폴더·영구 삭제. 전송 바이트 표시와 충돌 시 덮어쓰기/건너뛰기
- 선택한 암호의 운영체제 암호화 저장, SSH 키와 FTPS 인증서 지문 확인
- 정보 메뉴/상단 버튼에서 GitHub 최신 버전 확인, 운영체제·CPU에 맞는 파일 다운로드, SHA-256 검증 후 설치 파일 열기. 시작할 때 자동 확인은 설정에서 선택
- 정보 메뉴와 정보 창에 저장소, Chojema App Park, Blog, YouTube, X, Instagram, GitHub, Homepage 링크 제공

## 개선

- 한국어·영어 README를 설치·사용·업데이트·서버 연결 안내 중심으로 정리하고 내부 빌드·아이콘·릴리스 관리 절차 제거
- 업데이트·서버 기능에 맞춰 네트워크 통신과 로컬 암호 보관 안내 갱신

## 사용 시 참고

- 업데이트는 설치 파일을 연 뒤 사용자가 마무리합니다. macOS는 앱을 종료하고 DMG의 앱으로 기존 앱을 교체하세요.
- 서버 삭제는 휴지통을 사용하지 않는 영구 삭제이며 항상 확인합니다. 원격 파일을 열어 수정한 뒤에는 다시 업로드해야 합니다.
- FTP/FTPS는 Passive 모드·UTF-8·바이너리 전송을 사용합니다. 서버를 포함한 전송은 심볼릭 링크를 따라가지 않으며 중단된 전송의 이어받기는 지원하지 않습니다.
- macOS는 ad-hoc 서명(Apple 공증 없음), Windows는 상용 코드 서명이 없는 배포입니다.
