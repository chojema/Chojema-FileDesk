# Chojema FileDesk v0.1.0

출시일: 2026-11-07

[English](v0.1.0.en.md)

Chojema FileDesk의 첫 버전입니다.

## 새 기능

- 좌우 2패널 파일 관리자 (Windows, macOS)
- 두 패널 사이의 세로 도구 모음 (상위 폴더, 맨 위로, 새 폴더, 복사, 이동, 삭제, 맨 아래로, 현재 폴더에서 터미널 열기, 경로 복사, 파일·폴더 목록 복사)
- 드라이브·볼륨·자주 쓰는 폴더 바로가기
- 이름·확장자·크기·날짜 정렬
- 복사·이동·새 폴더·이름 바꾸기·휴지통으로 이동
- 같은 이름 충돌 시 모두 덮어쓰기 / 모두 건너뛰기
- 폴더 선택 시 폴더 크기 계산, 남은 디스크 공간 표시
- 뒤로·앞으로 이동, 경로 직접 입력, 빠른 이름 찾기
- 경로 표시줄의 방문했던 폴더 / 즐겨찾기 폴더 목록 (`Alt+↓`, `Ctrl/⌘+D`)
- 숨김 항목 표시/감추기: 숨김 속성 항목과 점(.)으로 시작하는 항목을 각각 설정, 숨겨진 항목 수 표시
- 한국어 / 영어 인터페이스, 밝은 / 어두운 테마

## 알려진 제한

- 끌어서 놓기(드래그 앤 드롭)는 아직 지원하지 않습니다.
- 코드 서명 인증서가 없어 처음 실행할 때 운영체제 경고가 나타날 수 있습니다. README의 "처음 실행할 때"를 참고하세요.
