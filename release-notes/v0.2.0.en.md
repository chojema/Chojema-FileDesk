# Chojema FileDesk v0.2.0

Release date: 2026-11-07

[한국어](v0.2.0.md)

## New

- FTP, explicit/implicit FTPS and SFTP connections, saved server profiles, password/SSH private key authentication, initial remote folder and pane selection
- Two-pane file/folder uploads and downloads, copy/move, rename, new folder and permanent remote deletion; byte progress and overwrite/skip conflict choices
- Optional OS-encrypted credential storage and SSH/FTPS server fingerprint verification
- GitHub release checks from the Information menu and top bar, matching OS/CPU downloads, SHA-256 verification and installer launch; optional startup checks
- Repository, Chojema App Park, Blog, YouTube, X, Instagram, GitHub and Homepage links in the Information menu and About window

## Improved

- Korean and English READMEs now focus on installation, use, updates and server connections; removed internal build, icon and release-maintenance instructions
- Updated network-access and local credential-storage information

## Notes

- Updates open a verified installer for you to complete. On macOS, quit FileDesk and replace the app using the downloaded DMG.
- Remote deletion is permanent and always asks for confirmation. Upload an edited temporary remote-file download again to save it on the server.
- FTP/FTPS use passive mode, UTF-8 and binary transfers. Transfers involving servers do not follow symbolic links; partial-transfer resume is not supported.
- macOS uses ad-hoc signatures without notarization; Windows artifacts have no commercial code signature.
