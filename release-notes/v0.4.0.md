## 새 기능

- 마우스 오른쪽 버튼 메뉴. Windows는 탐색기 메뉴, macOS는 Finder와 같은 메뉴(다음으로 열기, 정보 가져오기, 압축, 복제, 공유 등)
- 파일과 폴더를 앱 안팎과 패널 사이에서 끌어다 놓기
- 창 오른쪽 위에 날짜(요일), 시간, 키보드 입력 모드(한/영) 표시
- 파일 종류별 시스템 아이콘
- 하단 기능 키 표시줄을 설정에서 끄기

## 변경

- 업데이트 설치 파일을 열면 앱이 자동으로 종료
- 정보 메뉴의 링크를 프로그램 정보 창으로 정리

## 수정

- 창 높이를 줄이면 기능 키 표시줄이 패널을 가리던 문제
