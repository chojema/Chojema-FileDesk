# Chojema FileDesk v0.1.0

Release date: 2026-11-07

[한국어](v0.1.0.md)

The first release of Chojema FileDesk.

## New

- Dual-pane file manager for Windows and macOS
- Vertical toolbar between the panes (parent folder, top, new folder, copy, move, delete, bottom, open terminal in current folder, copy path, copy file/folder list)
- Shortcuts to drives, volumes and common folders
- Sort by name, extension, size or date
- Copy, move, new folder, rename and move to Trash
- Overwrite All / Skip All on name conflicts
- Folder size calculation on selection, free disk space display
- Back/forward navigation, direct path entry, type-ahead search
- Visited folders and favorite folders from the path bar (`Alt+↓`, `Ctrl/⌘+D`)
- Show/hide hidden items, with separate options for hidden-attribute items and dot items; hidden item count in the status bar
- Korean / English interface, light / dark theme

## Known limitations

- Drag and drop is not supported yet.
- The app is not code-signed, so the OS may warn on first launch. See "First launch" in the README.
